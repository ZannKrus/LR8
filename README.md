# 🎓 Калькулятор поступления УрФУ (Android)

Мобильное приложение для абитуриентов, позволяющее узнать доступные направления подготовки в НТИ УрФУ на основе баллов ЕГЭ. Приложение является клиентом для сервиса [nti.urfu.ru/ege-calc](https://nti.urfu.ru/ege-calc).

*Выполнено в рамках Лабораторной работы №8.*

## 📱 Функционал

*   **Ввод баллов ЕГЭ:** Поля для ввода баллов по всем предметам (Русский язык, Математика, Информатика, Физика, Химия, Обществознание, Иностранный язык, География).
*   **Валидация:** Проверка обязательного заполнения полей "Русский язык" и "Математика".
*   **Поиск направлений:** Отправка данных на сервер УрФУ и получение списка подходящих специальностей.
*   **Отображение результатов:** Список направлений с указанием проходных баллов.
*   **Интерфейс:** Использование Material Design компонентов (Cards, InputLayouts).

## 🛠 Технологический стек

*   **Язык:** Java
*   **SDK:** Android SDK
*   **Сеть:** [Retrofit 2](https://square.github.io/retrofit/)
*   **Парсинг JSON:** [GSON](https://github.com/google/gson)
*   **UI:** ConstraintLayout, ScrollView, Material Components

## 📡 Работа с API

Приложение взаимодействует с публичным API калькулятора ЕГЭ УрФУ.

**Endpoint:** `POST https://nti.urfu.ru/ege-calc/json`

**Тело запроса (JSON):**
```json
{
  "math": 70,
  "rus": 80,
  "inform": 85,
  "social": 0,
  "physics": 0,
  "chemistry": 0,
  "eng": 0,
  "geo": 0
}
```

**Ответ сервера (JSON):**
Сервер возвращает список объектов специальностей:
```json
[
  {
    "id": 4,
    "specialty_name": "Строительство",
    "math_point": 39,
    "rus_point": 40,
    "itk_point": 44,
    "phys_point": 39,
    ...
  },
  ...
]
```

## 🚀 Установка и запуск

1.  Клонируйте репозиторий:
    ```bash
    git clone https://github.com/ZannKrus/LR8.git
    ```
2.  Откройте проект в **Android Studio**.
3.  Дождитесь синхронизации Gradle.
4.  Запустите приложение на эмуляторе или реальном устройстве.
    *   *Требуется наличие интернет-соединения.*
